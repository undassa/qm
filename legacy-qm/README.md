# Архив: то, что пришло от qm

Здесь лежит всё, что mh унаследовал от qm и что больше не является рабочим
кодом продукта: рантайм на TypeScript (`src/`), его плагины (`plugins/`) и его
набор проверок (`test/`).

**Ничего отсюда не удалено.** Каталоги перенесены целиком, файл в файл: 1239
файлов рантайма и 391 файл остального хозяйства, столько же после переноса.
Здесь они лежат как источник — из них ещё предстоит взять то, что переезжает
на Rust.

## Почему это архив, а не удаление

Рабочий интерфейс теперь один — `web/` на React. Сервер к нему пишется заново на
Rust (`server-rs/`), и пока он не готов, интерфейс данных не получает. Это
осознанный промежуток, а не поломка.

Старый рантайм остаётся здесь по трём причинам:

1. **В нём живут проекции корпуса.** `src/projects/` разбирает документы в 45
   таблиц `project_*`, из которых интерфейс и читает. Rust будет замещать их по
   одной, и сверяться придётся с этим кодом.
2. **В нём же лежат ответы на вопросы, которых нет больше нигде** — почему
   правило устроено так, а не иначе. Комментарии здесь несут довод, а не пересказ.
3. **База уже наполнена им.** 137 таблиц в Postgres созданы этим кодом; пока Rust
   не умеет то же самое, единственный способ понять схему — прочитать её здесь.

## Что где

| каталог | что это |
|---|---|
| `src/` | рантайм: API, проекции корпуса, доставка, выкаты, кроны, интеграции |
| `src/projects/` | **важное**: разбор документов в таблицы `project_*` |
| `plugins/web-ui/` | прежний веб-интерфейс на lit и его сервер на Node |
| `plugins/{auth,portal,admin,onboarding,chassis}/` | вход, портал, админка, чассис |
| `test/` | набор проверок рантайма — 4343 штуки |
| `cli/`, `deploy/`, `scripts/`, `aws/`, `fly/`, `local/` | выкат и обслуживание |
| `docs/`, `adrs/`, `data/`, `skills-seed/` | документация, решения, затравки |
| `.github/` | сборки CI: все они гоняют проверки этого рантайма |
| `package.json`, `node_modules/`, `tsconfig*.json`, `.env` | обвязка Node — переехала вместе с тем, что её читает |

## Как это запустить, если понадобится

Дерево самодостаточно: `package.json` лежит рядом со своим `src/`, `node_modules/`
и `.env`, поэтому команды работают из этого каталога, а не из корня.

```bash
cd legacy-qm && npm test
```

## Чего здесь искать не надо

React-интерфейс сюда не попал: он переехал в `web/`, обзавёлся своим
`@types/node` вместо поднятого из корня и от этого дерева не зависит ни одной
строкой. Единственное, что он отсюда взял, — раскладку волн
(`plugins/web-ui/src/task-waves.ts`), и она скопирована в `web/src/lib/`.

Прежний `README.md` продукта лежит рядом под именем `README-product.md`: он
описывает qm как продукт — слак, выкаты, скоупы, — то есть ровно то, что
осталось здесь.
