# Съёмка и обход

Интерфейс проверяется НЕ глазами. Два инструмента, оба ходят настоящим
браузером по живому серверу.

    node tools/shot.mjs <куда> '[["имя","?page=where"]]' [ширина]
    node tools/walk.mjs

`shot.mjs` снимает раздел ЦЕЛИКОМ. Обычный `fullPage` тут не годится: каркас —
окно в `100vh` с прокруткой внутри `.main`, и снимок вышел бы ровно в высоту
окна независимо от того, сколько там содержимого. Инструмент растит окно под
внутреннюю прокрутку и заодно называет высоту — по ней видно, что раздел стал
нечитаемым от собственного размера, раньше чем это заметит человек.

`walk.mjs` проходит действиями: переключает фазы, разворачивает пункты, водит
палитру клавишами, открывает каждый раздел и ловит ошибки страницы. Раздел,
который рисуется, но падает при щелчке, снимок не поймает.

## Личность

Серверу нужна печенька `mh_identity`. Выписывается тем же секретом, которым
сервер её проверяет:

    set -a; . ../server-rs/.env; set +a
    export MH_TOKEN=$(python3 - <<'PY'
    import os,hmac,hashlib,base64,json,time
    sec=os.environ['PORTAL_IDENTITY_SECRET'].encode()
    b64=lambda b: base64.urlsafe_b64encode(b).rstrip(b'=').decode()
    body=b64(json.dumps({"p":"кто-то","exp":int(time.time()*1000)+3600_000},
                        ensure_ascii=False,separators=(',',':')).encode())
    print(f"{body}.{b64(hmac.new(sec,body.encode(),hashlib.sha256).digest())}")
    PY
    )

Без неё каждый запрос отвечает `401`, а страница рисуется пустым каркасом —
и это выглядит как поломка вёрстки, а не как отказ входа.
